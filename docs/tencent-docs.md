# 腾讯文档写入

用户将提供新的文档链接。本项目不使用旧的「每日案例」文档，也不向其自动化出站队列写入文件。

## 只提供链接

链接可以作为目标地址。若当前浏览器已登录且该文档允许编辑，助手可以使用浏览器写入已准备内容，随后回读核对。若页面要求登录、验证码或显示无编辑权限，则需要用户完成相应操作。只读链接本身不能授予编辑权限。

在收到新链接前，`data/runtime/exports/tencent-docs-pending.json` 保存字段映射、案例 ID、内容哈希和待写入记录；TSV 可用于智能表格导入。普通文档可使用 Markdown 报告。清单状态为 `awaiting_document`，不是 `synced`。收到目标后再按文档类型适配，先查案例 ID 避免重复，写入后回读核验。

## 后台无人值守

网页链接不等于应用的 API 凭证。由助手在已登录浏览器中完成一次写入，与工作台每天无人值守同步是不同能力。后台稳定同步还需要腾讯文档支持的 Token/OAuth/MCP 授权及目标工具参数，不能从浏览器私自提取凭证。

代码中的 `tencent_docs_registry.py` 保留远程适配入口，目前只验证了本地模拟契约，尚未对用户的新文档完成真实写入和回读。普通文档与智能表格的工具及参数不同，需以实际文档与服务 tools/list 为准。现阶段本地 SQLite 是完整的个人案例库。
