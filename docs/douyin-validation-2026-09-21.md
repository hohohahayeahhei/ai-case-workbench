## 本地工程验证

本次补丁后的完整自查运行 250 项 unittest，通过且跳过 1 项可选 PyAV 实机测试；官方 MCP 协议检查、离线采集 smoke 和前端生产构建均通过。跳过原因为项目测试虚拟环境未安装可选 PyAV；实际转写运行环境另行完成了下述真实视频时长校验。这些数量为工程检查结果，不是线上内容质量评测。

- 实际 SQLite、FastAPI 和 React 页面完成链接录入、重复导入、作者/页面日期保存、时间证据录入、状态变化和发现任务展示的联调。测试用独立临时数据库；受控作品和文字均不进入正式案例库。
- 核心测试涵盖口述主张、可见演示、图文定位、重复作品、不可用/验证状态、日期缺失、素材路径与容量、并发写入、机器证据核实标志与有限重试。
- 原抽取、核验、评分、独立复审流程用受控证据和受控模型完成端到端入库验证；重复执行不再调用模型，新证据重新审核。结果引文不绑定画面/外部结果时阻止入选。
- 三个抖音 MCP 工具经官方 SDK stdio 实际往返验证，只读本地记录及浏览器操作计划，不把工具调用描述为执行了在线搜索。
- 修复了来源 Skill 全局附加会使历史网页评分失效的问题，增加普通文章指纹兼容测试。修复超过二十条待审核队列时指定作品未被处理的问题。
- 首轮缺少本地转写依赖时，受控静音音频在真实本地处理路径返回 `transcription_failed`、证据为零、素材保留。随后已配置 faster-whisper、base 模型和 PyAV，并完成一条真实视频转写。未部署自动 OCR 或画面理解引擎，本次画面核对由 Codex 逐帧执行。

- 正式服务新增的 13 项 ASR 依赖已固定版本，原有 76 项依赖版本未改变，`pip check` 通过。配置仅新增本地转写模型字段，base 模型持久化保存在本机并排除于 Git。
